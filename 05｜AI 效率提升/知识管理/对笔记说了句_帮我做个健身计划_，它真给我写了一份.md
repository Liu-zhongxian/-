![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=Mzc0YTNhNmNjM2E4MWQ2YzkyOWMwYTI2MDI1NzE0MDRfMjkwMzk2NDU3YzViZmMzYTExOWQzNGVmNmMzZTBkYWRfSUQ6NzY0NTI2NjA2MzI1NjgwMDQzNl8xNzgyMTA3MzA1OjE3ODIxMTA5MDVfVjM)

你的笔记现在在哪？

我猜：备忘录里一堆，微信收藏吃灰，Notion 开一次卡一次，飞书文档翻半天找不到。

我之前也是这样。后来用了 Obsidian，再给它接上 AI，整个人都不一样了。

今天就教你两件事，5 分钟搞定：

① 下载 Obsidian，写下第一条笔记

② 装个 AI 插件，让笔记自己"长脑子" ✅ 提前说下，下面的截图很多不是麻烦，而是我为了让小白也能看清楚一步一步的截出来的，其实很简单，不要被吓到！

𝟭. 先把 Obsidian 装上

为啥用这个不用别的？四个字：本地、免费。

- 笔记存在你自己电脑上，不怕哪天服务跑路
- Markdown 格式，纯文本，秒开不卡
- 插件多到离谱，后面你就知道了

去 [obsidian](https://obsidian.md/)下载，选你的系统装上就行。

![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=NWQ2MjI4MGM5ZDBlYWJhMjc4YjdiN2U0MzE5ODUzMDJfOTZlNjc2YjAzMTIzOTE1ZDRlOTVjMDFlOGQ5ZmVmODVfSUQ6NzY0NTI2NjA2NTMwNzc2NTk1OV8xNzgyMTA3MzA1OjE3ODIxMTA5MDVfVjM)

𝟮. 建个仓库

装好打开，Obsidian 会让你选怎么开始。

点「新建仓库」，起个名字，选个文件夹，完事。

仓库就是个文件夹，没什么高级的，你所有笔记以后都在这里面。

![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=MzkyYzVhZTc3MDk3Mzg1MjdmMTEwN2M2NDE5NjJlNDdfZTEwNWZhMGJiMTllMzI3MDgyMjZmYWE2YjBmMWU0NGVfSUQ6NzY0NTI2NjA2NTYwOTYyNDc3OV8xNzgyMTA3MzA1OjE3ODIxMTA5MDVfVjM)

𝟯. 写第一条笔记

点左上角新建（或者快捷键 ⌘N），随便写点啥。

"Hello Obsidian" 也行，今天午饭吃了啥也行。

![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=YzZhMjUzMTc3NzNhOThjMDNiYmZjYjhlOGQ0OWE5M2NfNmNhNDMxYjRmZGZkZDE3YzVmOTA2OTMwOGEwMGVkOWVfSUQ6NzY0NTI2NjA2MzM3ODU0OTk1Nl8xNzgyMTA3MzA1OjE3ODIxMTA5MDVfVjM)

你会发现这编辑器特别干净，没有乱七八糟的工具栏，就你和文字。

![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=NWIwOTVlOTM5ZDEyZTBkMDVhY2U4NThlOGRhM2MxZmZfMDJlYTNhYTA2Yjc0OTQ5OGI0YTQ3ZGYyNGQ5Zjc0MGVfSUQ6NzY0NTI2NjA2MzY5NzcyNjY3Nl8xNzgyMTA3MzA1OjE3ODIxMTA5MDVfVjM)

OK，Obsidian 搞定了。下面才是今天的重点。

𝟰. 给笔记接上 AI

接下来装一个叫 Claudian 的插件。

装完之后你可以直接在笔记里跟 AI 聊天，让它帮你写东西、整理内容，甚至自动管文件。听着玄乎，装完你就懂了。

过程稍微长一点，跟着截图走就行。

𝗦𝘁𝗲𝗽 𝟭: 装 Claude Code

Claudian 底层跑的是 Claude Code，先把它装上。打开终端：

```Bash
npm install -g @anthropic-ai/claude-code

```

装好之后敲 which claude，能看到路径就说明成功了。记一下这个路径，待会要用。

![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=NjIyYmRhMTE0MGU3ZDFhNTZlMzM3NDRhNTMxMjliNjVfOTgyMWUxNTliNDQzY2E3Mzg0MzgyY2VmOWMwZjhkN2VfSUQ6NzY0NTI2NjA2Mzg2MDk3Njg0N18xNzgyMTA3MzA1OjE3ODIxMTA5MDVfVjM)

（API Key 怎么搞？看雨哥这篇 [Antigravity Tools](https://x.com/xiangxiang103/status/2019349337143406796?s=20) 的文章就行，自己有 Claude 订阅或者用中转站也可以。）

![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=YTFmZmU3Y2Q1NDM1MDZiNzdmMWQ1NzY1YjlhYzMzNmRfNDllMzRkZjUxYjAyNDIxMGVkZTIxMDIwZThkZTE3NjBfSUQ6NzY0NTI2NjA2NTk1NzY4NjQ3M18xNzgyMTA3MzA1OjE3ODIxMTA5MDVfVjM)
