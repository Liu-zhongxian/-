# Codex 驯化协议，让 AI 越用越懂你的长期记忆工作区

很多人装了 Codex / Cursor 这类 AI 助手后越用越乱：它不认识你、不记得你的习惯、每次都从零开始，还总在同一个地方反复犯错。这份协议就是解决这个问题的一套可直接落地的方法：给 AI 建一个"长期记忆工作区"——用一份个人信息档案让它认识你和你的电脑，用一份行为规范给它立规矩，再用一个"踩坑日志"让它把犯过的错自己记下来。犯过的错不再犯，于是越用越聪明。

协议包含三部分：① 一键安装指令词——复制一段话丢给 AI，它自动把整套工作区建好，零门槛；② 核心指令词——日常驱动它的几条关键 prompt；③ 文档模板原文——6 个文件完整内容，手动搭或检查 AI 都能照着来。

适合用 Codex / Cursor 做开发、做内容、做提效，又觉得"AI 没记性、越用越不顺手"的人。打开协议，复制安装指令词发给 AI，再把个人信息填上即可开始。
